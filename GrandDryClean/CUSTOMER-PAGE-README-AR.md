# صفحة عملاء GRAND DRY CLEAN

- الصفحة الرئيسية للعملاء: `index.html`
- التنسيق: `css/customer.css`
- تفاعلات قائمة الخدمات وسلة الطلب: `js/customer.js`
- رابط واتساب: `201037626070` بصيغة دولية داخل الرابط.
- رابط اللوكيشن: رابط Google Maps الذي زوده المستخدم.

## الوضع الحالي
- تصميم مؤقت متجاوب مع الهواتف.
- قائمة خدمات مبدئية قابلة للتعديل داخل `js/customer.js`.
- الأسعار غير محددة عمدًا حتى تزويدنا بالأسعار المعتمدة.
- العميل يختار الخدمات والكميات، ثم يفتح واتساب برسالة جاهزة ليضغط إرسال بنفسه.
- لا توجد قاعدة بيانات ولا حفظ لبيانات العميل أو الطلب.
- الصور المستخدمة حاليًا رموز توضيحية وليست صور منتجات نهائية.

## تعديل الخدمات والأسعار
عدّل مصفوفة `PRODUCTS` داخل `js/customer.js`.
لكل صنف: `id`, `name`, `category`, `description`, `icon`, `price`.
اترك `price: null` إلى أن يتم اعتماد السعر. عند وضع رقم ستحتاج لاحقًا إلى تحديث واجهة عرض السعر وطريقة حساب الطلب إذا رغبت في إظهار الإجمالي.
