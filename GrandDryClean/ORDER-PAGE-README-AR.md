# صفحة طلب عملاء GRAND DRY CLEAN

## الروابط المنفصلة
- صفحة العملاء الرئيسية: `GrandDryClean/index.html`
- صفحة إنشاء الطلب: `GrandDryClean/order.html`
- تسجيل دخول الإدارة: `GrandDryClean/login.html`
- لوحة إدارة المغسلة: `GrandDryClean/dashboard.html`

## مكونات صفحة الطلب
- صفحة عامة لا تتطلب تسجيل دخول.
- تصفح الخدمات حسب القسم: غسيل وكي، تنظيف جاف، مفروشات.
- إضافة القطع وتعديل الكميات قبل الإرسال.
- نموذج بيانات العميل: الاسم ورقم الهاتف، مع عنوان وملاحظات اختياريين.
- إرسال تفاصيل الطلب برسالة جاهزة إلى واتساب المغسلة `+20 100 585 4115`.
- الأسعار غير معروضة؛ يتم تأكيدها مع العميل عبر واتساب.
- لا تحفظ الصفحة الطلبات أو بيانات العملاء في قاعدة بيانات، ولا تصل إلى لوحة الإدارة.

## مهم
صفحة العملاء مستقلة في `order.html`، وصفحة الإدارة تبقى محمية عبر `login.html` و`dashboard.html`. لم يتم تغيير تسجيل الدخول أو أذونات Supabase.
