# حزمة بيانات وصور Dina's Corner

تحتوي على ملفات البيانات المصدرة، صور الأقسام الثمانية، وصور المنتجات النشطة السبعين فقط.
تم مطابقة أسماء ملفات صور المنتجات مع مسارات الصور المسجلة في asset-manifest.csv.
تم استبعاد 48 صورة غير موجودة في قائمة الصور المطلوبة حاليًا.
لم يتم تعديل أي ملفات بالموقع الأصلي أو حذف أي بيانات من Supabase.

الصور المميزة/العروض لم تُضم بعد؛ يجب نقلها من bucket poac-home-featured-products في خطوة منفصلة.
