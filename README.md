# POAC — GRAND DRY CLEAN (Temporary UI)

حزمة واجهة مؤقتة لتصميم تسجيل دخول POAC ولوحة إدارة GRAND DRY CLEAN.

## الملفات
- `index.html`: صفحة تسجيل الدخول POAC (تجريبية وغير متصلة بالمصادقة).
- `dashboard.html`: لوحة إدارة تجريبية للأصناف.
- `css/poac.css`: التصميم المتجاوب.
- `js/login.js`: سلوك نموذج الدخول التجريبي.
- `js/dashboard.js`: بيانات أصناف تجريبية وإضافة مؤقتة داخل المتصفح.
- `sql/README-SUPABASE.md`: ملاحظات الربط الآمن لاحقًا.

## التشغيل
افتح `index.html` لمعاينة صفحة الدخول. يمكن فتح `dashboard.html` مباشرة لمعاينة لوحة الإدارة.

## مهم
هذه نسخة تصميم فقط: لا تنشئ مستخدمًا حقيقيًا ولا تتحقق من كلمات المرور ولا تحفظ الأصناف بعد إغلاق الصفحة. لم يتم تضمين أي مفاتيح أو بيانات اتصال Supabase. قبل الربط، راجع قاعدة Dina’s Corner وسياسات RLS لتجنب كشف بيانات المشاريع أو التأثير على النظام الحالي.


## لوحة GM للمغسلة
- `gm.html`: لوحة إدارة GRAND DRY CLEAN.
- `css/gm.css`: تنسيق لوحة GM.

- افتح `gm.html` مباشرة لمعاينة لوحة GM.
- إضافة وتعديل وحذف الأصناف والأقسام تعمل مؤقتًا داخل الذاكرة فقط؛ إعادة تحميل الصفحة تعيد بيانات العينة.
- رفع الصورة للمعاينة فقط ولا يتم رفعها إلى GitHub أو Supabase.
- لا يوجد تسجيل دخول حقيقي أو اتصال بقاعدة البيانات في هذه النسخة.
