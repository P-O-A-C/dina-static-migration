إعداد صور السلايدر الرئيسية - GRAND DRY CLEAN

1) افتح Supabase ثم SQL Editor.
2) نفّذ ملف GDC-HOMEPAGE-SLIDES-SETUP.sql مرة واحدة.
3) ارفع ملفات المشروع إلى GitHub مع الحفاظ على المسارات.
4) افتح لوحة إدارة المغسلة > الأكثر طلبًا.
5) ستجد قسم "صور الصفحة الرئيسية المتحركة" أعلى اختيار الأصناف. أضف حتى 6 صور، ويمكن تغييرها أو إخفاؤها أو حذفها أو تغيير ترتيبها.
6) افتح صفحة العملاء بعد تحديث كامل. الصور النشطة فقط تظهر في السلايدر.

ملاحظات:
- يستخدم الرفع مساحة التخزين الحالية gdc-service-images.
- عند عدم إضافة أي صور مخصصة، تظل صور السلايدر الافتراضية الحالية ظاهرة.
- لا تتأثر صور الأصناف أو بيانات الطلبات بهذا التعديل.
