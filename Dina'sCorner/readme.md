# صفحات إدارة Dina’s Corner القديمة

هذا المجلد يحتوي صفحات إدارة قديمة منفصلة عن صفحات العملاء العامة في جذر المستودع (`/welcome.html` و`/menu.html`).

بعض الصفحات هنا ما زالت تحمّل `assets/config.js` و`assets/app.js` وتستدعي Supabase. لا تعتبرها نسخة الإدارة المنقولة إلى GitHub، ولا تستخدمها كدليل على أن فصل الإدارة اكتمل. احتُفظ بها في هذه الحزمة كما هي حتى لا تُحذف وظائف أو مراجع مطلوبة قبل اعتماد بديل آمن.
