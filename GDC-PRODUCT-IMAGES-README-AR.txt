GRAND DRY CLEAN — استيراد صور الأصناف دفعة واحدة

محتويات المجلد:
- GrandDryClean/assets/products/: 31 صورة منتج بأسماء ملفات ثابتة.
- GDC-PRODUCT-IMAGES-IMPORT.sql: يربط الصور بالأصناف الموجودة ويضيف الأصناف الناقصة.

خطوات التنفيذ:
1) ارفع المشروع إلى GitHub Pages أولًا، وبالأخص مجلد GrandDryClean/assets/products/.
2) بعد نشر GitHub Pages، افتح Supabase > SQL Editor.
3) نفّذ ملف GDC-PRODUCT-IMAGES-IMPORT.sql مرة واحدة.
4) افتح لوحة الإدارة ثم صفحة العملاء بعمل تحديث كامل Ctrl+Shift+R.

ملاحظات:
- تم إدراج 31 صورة، منها 29 ملفًا مسمى وملفان تم التعرف عليهما كـ مريلة وتونيك.
- لم يتم وضع أي أسعار؛ ستظهر الأسعار كـ "لم يحدد" إلى أن تضيفها من الإدارة.
- تم توزيع الأصناف على الأقسام الموجودة: غسيل وكي، تنظيف جاف، مفروشات.
- إذا كان الصنف موجودًا مسبقًا بنفس الاسم، يتم تحديث رابط صورته فقط ولا يتم تعديل سعره أو وصفه.
- الأصناف الجديدة تُضاف نشطة وبلا سعر وبلا وصف حتى تحددها من لوحة الإدارة.
- الصور مستضافة داخل ملفات GitHub Pages وليست Supabase Storage؛ لذلك لا تحتاج إعداد bucket أو سياسات Storage إضافية.
- لم أدرج صورًا للبطاطين أو الستائر لأن الملف المرفوع لا يحتوي صورًا باسم هذين الصنفين.
